Body prose for the essay: serif at `fs-body`/`lh-body`, held to `--measure`, with h2 sections and h3 subsections.

**Provide:** an `article.cp-prose` of `p`, `h2`, `h3`, inline `code`, `a`, `dfn`, and optional `div.cp-aside` notes.

- h2 always opens with `span.cp-sec` (`§ 02`) — the numeral is the section's address in the course.
- Use `dfn` once, at a term's first definition; it gets a `c1-soft` highlighter.
- `.cp-aside` is for one-paragraph sidebars (NOTE, WHY, GOTCHA) set in sans `fs-small`; never nest figures in it.
- Don't bold for emphasis more than once a paragraph; italics are the default emphasis.
- Links are `accent` with a 1.5px underline; never remove the underline.
